CC50 SHRUBLAND EXPERIMENT COMPARISON by Amin
====================================

Purpose
-------
Evaluate whether:
1. the conservative CC50 Shrubland reference revision alone, or
2. the same CC50 reference combined with a 10x WeightedRandomSampler

can resolve the failure of the Swin-UNETR model to detect Shrubland.

Both experiments used the same:
- CC50 reference
- Sentinel-1 inputs
- train/validation split
- Swin-UNETR architecture
- class-weighted CrossEntropyLoss
- optimizer
- scheduler
- early stopping configuration
- validation data
- full-scene evaluation procedure

The only intended difference between the two training runs was the
WeightedRandomSampler in the second experiment.

============================================================
6. INTERPRETATION
============================================================

The CC50 reference revision alone did not resolve Shrubland collapse.
The clean baseline never predicted class 5.

The 10x WeightedRandomSampler forced the model to produce Shrubland
predictions, but the resulting predictions were overwhelmingly false.

Only 39 of 3716 true Shrubland pixels were detected.

Only 39 of 26056 predicted Shrubland pixels were correct.

Most false Shrubland predictions originated from Forest.

The sampler therefore appears to shift part of the Forest/vegetation
decision boundary toward Shrubland without learning a reliable
Shrubland representation.

At the same time, all major global metrics decreased relative to the
clean baseline.

The 10x binary patch sampler should therefore not be considered an
effective solution to the Shrubland problem.


============================================================
7. CURRENT CONCLUSION
============================================================

The experiments indicate that:

1. Improving the reference with the conservative CC50 rescue is not
   sufficient by itself.

2. Increasing Shrubland-patch exposure from approximately 13% to
   approximately 60% through a 10x WeightedRandomSampler produces only
   ~1% Shrubland recall.

3. This small recall increase is accompanied by approximately 26,000
   false-positive Shrubland pixels and deterioration in global model
   performance.

4. Shrubland remains primarily confused with Forest and Grassland.

5. Further changes to the rare-class learning strategy should be
   discussed before another experiment is launched.
